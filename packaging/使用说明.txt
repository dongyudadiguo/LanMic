LanMic — 用手机当 Windows 麦克风（口述写提示词）
==============================================

1. 解压整个文件夹，不要只拷贝 LanMic.exe。
2. 双击 LanMic.exe（没有黑框）。浏览器会打开控制台页，右下角出现托盘绿点。
3. 手机连同一 Wi-Fi，用 Chrome / Edge 扫控制台里的二维码。
4. 第一次证书不受信任：点「高级 → 继续前往」，再允许麦克风。
5. 要给 Win+H 用，请先安装免费虚拟声卡：
   https://vb-audio.com/Cable/
   然后在 Windows 声音输入里选「CABLE Output」。
6. 退出：右下角托盘绿点 → 退出，或控制台页上的「退出 LanMic」。
   只关网页不会退出程序。

Windows 可能提示「未知发布者 / SmartScreen」：更多信息 → 仍要运行。
防火墙若询问，请允许专用网络。

日志与证书：%USERPROFILE%\.lanmic\
