口述写提示词（推荐流程）

  1. 手机点「开始当麦克风」，对着手机说话，看上面电平条是否跳动。
  2. Windows 设置 → 系统 → 声音 → 输入，选 CABLE Output（或 VoiceMeeter 对应输入）。
  3. 打开要写提示词的地方（浏览器对话框、编辑器、笔记）。
  4. 按 Win + H 打开语音输入，开始口述。停顿一下会自动上字。
  5. 说完再改一改标点。长提示词可以分段说：「下一段」「换行」。
